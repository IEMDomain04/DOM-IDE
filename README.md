## To run the IDE on your local machine

Note: Make sure you have the following installed on your system:
<br>1. Git
<br>2. Node.js and npm
<br>3. Python (with pip for managing Python packages)

<h3> Step 1: Clone the Repository </h3>

```bash
git clone https://github.com/IEMDomain04/DOM-IDE.git
```

<h3> Step 2: Install Dependencies </h3>
This will install the needed Node.js dependencies for the frontend.

```bash
npm install
```

<br>

This will install Flask, the lightweight Python web framework used for the backend + other python dependencies.

```bash
pip install -r requirements.txt
```

<br>

Axios is used in the React frontend for making HTTP requests.

```bash
npm install axios
```

<h3> Step 3: Run the Backend Server on your terminal </h3>

```bash
python server.py
```

<h3> Step 4: Run the Web App from a separate terminal </h3>

```bash
npm run dev
```

Press the http://localhost:3000 or just type localhost:3000
